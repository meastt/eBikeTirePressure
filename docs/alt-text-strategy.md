# Alt Text Strategy for E-Bike PSI

## Purpose
Alt text (alternative text) provides textual descriptions of images for:
- Screen readers used by visually impaired users
- SEO optimization for image search
- Fallback content when images fail to load

## Guidelines

### 1. Be Descriptive and Specific
- Describe what the image shows, not what it means
- Include relevant details like bike model, brand, or component
- Keep it concise (under 125 characters when possible)

**Examples:**
- ❌ Bad: "Bike"
- ✅ Good: "Lectric XP 3.0 fat tire e-bike with 20-inch wheels"

### 2. Include Context Relevant to Content
- Reference the page topic (tire pressure, PSI, e-bikes)
- Mention specific models or brands when relevant
- Include technical specifications when shown

**Examples:**
- ❌ Bad: "Person riding"
- ✅ Good: "Rider checking tire pressure on Rad Power RadRunner cargo e-bike"

### 3. Avoid Redundancy
- Don't start with "Image of" or "Picture of"
- Don't repeat information already in surrounding text
- Skip alt text for purely decorative images (use empty alt="")

**Examples:**
- ❌ Bad: "Image of a tire pressure gauge showing 25 PSI"
- ✅ Good: "Tire pressure gauge showing 25 PSI"

### 4. SEO Considerations
- Include relevant keywords naturally
- Reference brand names and model numbers
- Use terms users might search for

**Keywords to consider:**
- E-bike, electric bike, ebike
- Tire pressure, PSI
- Brand names (Rad Power, Lectric, Aventon, etc.)
- Bike types (cargo, fat tire, commuter, etc.)

### 5. Decorative vs. Informative Images

**Decorative images** (use empty alt=""):
- Background patterns
- Decorative icons without functional purpose
- Images that duplicate adjacent text

**Informative images** (require descriptive alt text):
- Product photos
- Diagrams and charts
- Logos and branding
- Instructional images

## Image Types on E-Bike PSI

### Bike Model Images
Format: `[Brand] [Model] [Type] e-bike [distinctive feature]`

**Examples:**
- "Aventon Aventure 2 fat tire e-bike with 26x4.0 tires"
- "Tern GSD S10 cargo e-bike with dual battery setup"
- "Specialized Turbo Vado commuter e-bike"

### Component/Detail Images
Format: `[Component] on [Brand Model] showing [detail]`

**Examples:**
- "CST BFT tire sidewall showing 20-80 PSI rating on Lectric XP"
- "Schwalbe Super Moto-X tire on Riese & Müller Load 75"
- "Digital tire pressure gauge displaying 28 PSI"

### Instructional Images
Format: `[Action being demonstrated] on [bike/component]`

**Examples:**
- "Checking tire pressure with digital gauge on e-bike front wheel"
- "Comparing pinch flat vs properly inflated fat tire"
- "Adjusting PSI for different terrain types diagram"

### Logo and Branding
Format: `[Brand name] logo` or `[Product name] logo`

**Examples:**
- "Rad Power Bikes logo"
- "E-Bike PSI calculator icon"
- "Lectric eBikes wordmark"

## Implementation Checklist

When adding images to the site:

- [ ] Write descriptive alt text following guidelines above
- [ ] Keep alt text under 125 characters when possible
- [ ] Include brand/model names for bike images
- [ ] Reference technical specs when visible (tire size, PSI, etc.)
- [ ] Use empty alt="" for decorative images only
- [ ] Test with screen reader if possible
- [ ] Review for natural keyword inclusion (no stuffing)
